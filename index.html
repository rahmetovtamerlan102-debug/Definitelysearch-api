Definitelysearch API

Документация

Интегрируйте наш поиск в свои проекты. Чистый JSON, высокая скорость и надежность.

Авторизация

Все запросы к API требуют авторизации. Передайте ваш ключ в заголовке X-API-Key или в параметре ?key=.

# Пример с заголовком
curl -H "X-API-Key: ВАШ_КЛЮЧ" \
     "https://dox2.onrender.com/api/v1/search?q=..."

Поиск данных

GET /api/v1/search

Универсальный эндпоинт для поиска по всем базам. Поддерживает поиск по телефону, ФИО, Telegram ID и другим параметрам.

Параметр Тип Описание
q string Поисковый запрос. Обязателен.
type string Тип поиска: phone, fio, tgid. По умолчанию: fio.
key string API-ключ (если не используется заголовок).

Пример запроса

curl -s "https://dox2.onrender.com/api/v1/search?key=test_key_123&type=phone&q=%2B79059410984"

Успешный ответ

API возвращает объект с метаданными и массивом data, содержащим найденные записи.

{
  "success": true,
  "query": "+79059410984",
  "type": "phone",
  "total": 11,
  "timings_ms": 120,
  "data": [
    {
      "source": "vitaexpress",
      "fio": "Анна Кукина",
      "phone": "79059410984",
      "email": "kukina_ann@mail.ru"
    }
  ]
}

Ошибки

HTTP Код Описание
400 Не передан параметр q.
401 Требуется API-ключ.
403 Неверный ключ или истёк срок действия.
429 Превышен лимит запросов (100 в минуту).
Получить API-ключ

Ключи выдаются автоматически через Telegram-бота.

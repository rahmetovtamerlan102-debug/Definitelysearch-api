Definitelysearch API Правила API
#

Обзор

Definitelysearch API — единый шлюз для поиска по открытым данным. Поддерживает 3 типа поиска: ФИО, номер телефона и Telegram ID.

Базовый URL: https://dox2.onrender.com
Все эндпоинты возвращают JSON. Кодировка ответа — UTF-8.

# Авторизация

Для доступа к API требуется ключ. Передавайте его одним из двух способов.

X-API-Key HTTP-заголовок рекомендуется

Передаётся в заголовке запроса. Безопаснее, чем query-параметр.

?key= Query-параметр

Передаётся в URL. Удобно для тестирования через curl/браузер.

Безопасность: Никогда не используйте API-ключ в клиентском JavaScript на сайтах — он будет виден в коде. Всегда проксируйте запросы через свой сервер.

# Endpoints

Все доступные методы API.

GET /api/v1/search?q={запрос}&type={тип}

Поиск по данным

GET /api/v1/check-key

Проверить статус ключа

Параметры /search

Параметр Тип Обязательный Описание
q string Да Поисковый запрос
type string Нет Тип поиска (по умолчанию: fio)
key string * API-ключ (если не передан в заголовке)

Типы поиска

Тип Описание
fioПоиск по ФИО
phoneПоиск по номеру телефона
tgidПоиск по Telegram ID

# Поиск

Выполнение поискового запроса к API.

Пример запроса

        

            cURL
            
        

        curl -s "https://dox2.onrender.com/api/v1/search?key=ВАШ_КЛЮЧ&q=Иванов+Иван&type=fio"

Успешный ответ

        

            200 OK
        

        { "success": true, "data": [ { "name": "Иванов Иван Иванович", "phone": "7-999-123-45-67", "address": "г. Москва, ул. Примерная, д. 1" } ] }

Проверка ключа

        

            cURL
            
        

        # Быстрая проверка валидности API-ключа
curl -s "https://dox2.onrender.com/api/v1/check-key?key=ВАШ_КЛЮЧ"

# Ошибки

API возвращает стандартизированные HTTP-статусы и JSON с описанием ошибки.

HTTP Сообщение Описание
400Параметр q обязателенНе передан поисковый запрос
401Требуется API-ключКлюч не указан ни в заголовке, ни в URL
403Неверный API-ключКлюч не найден в базе
403Срок действия ключа истёкКлюч просрочен
429Превышен лимит. Пауза X мин.Rate limit + strike-система
500ошибка на стороне сервераВнутренняя ошибка сервера

Strike-система

При превышении лимита в 100 запросов/минуту включается прогрессивный кулдаун:

НарушениеДлительность
1-е5 минут
2-е10 минут
3-е30 минут
4+60 минут
После окончания кулдауна счётчик обнуляется. Система начинается заново с 5 минут.

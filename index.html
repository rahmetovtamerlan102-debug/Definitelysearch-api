API Documentation

Единый шлюз для поиска по сотням баз данных. Чистый JSON, высокая скорость и надёжность.

Авторизация

Для доступа к API используйте ваш персональный ключ. Передавайте его в заголовке X-API-Key или в параметре ?key=.

# Пример с заголовком
curl -H "X-API-Key: test_key_123" \
     "https://dox2.onrender.com/api/v1/search?q=..."

Поиск данных

GET /api/v1/search

Универсальный эндпоинт для поиска.

Параметр Тип Описание
q string Поисковый запрос (телефон, ФИО, TG ID). Обязателен.
type string Тип поиска: phone, fio, tgid. По умолчанию: fio.
key string Ваш API-ключ (если не используется заголовок).

Пример ответа

API возвращает структурированный JSON. Массив data содержит список найденных записей.

{
  "success": true,
  "query": "+79059410984",
  "type": "phone",
  "total": 11,
  "timings_ms": 120,
  "data": [
    {
      "source": "vitaexpress",
      "fio": "Анна Кукина",
      "phone": "79059410984",
      "email": "kukina_ann@mail.ru"
    }
  ]
}

Ошибки

Код Описание
400 Не передан обязательный параметр q.
401 Требуется API-ключ.
403 Неверный ключ или истёк срок действия.
429 Превышен лимит запросов (100 в минуту).

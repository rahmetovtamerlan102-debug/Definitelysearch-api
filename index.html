Definitelysearch

API Документация

Единый шлюз для поиска по открытым и закрытым данным.

Авторизация

Для доступа к API требуется ключ. Передавайте его в заголовке X-API-Key или в параметре ?key=.

curl -H "X-API-Key: ВАШ_КЛЮЧ" "https://dox2.onrender.com/api/v1/search?q=..."

Поиск

GET /api/v1/search

Универсальный поиск по базе данных.

ПараметрТипОписание
qstringПоисковый запрос (обязательно)
typestringТип поиска: phone, fio, tgid
keystringВаш API-ключ

Пример запроса

curl -s "https://dox2.onrender.com/api/v1/search?key=test_key_123&type=phone&q=%2B79059410984"

Успешный ответ

{
  "success": true,
  "query": "+79059410984",
  "type": "phone",
  "total": 11,
  "timings_ms": 120,
  "data": [
    {
      "source": "vitaexpress",
      "fio": "Анна Кукина",
      "phone": "79059410984",
      "email": "kukina_ann@mail.ru"
    }
  ]
}

Ошибки

HTTPОписание
401Требуется API-ключ
403Неверный API-ключ или срок истёк
429Превышен лимит (100 запросов в минуту)
